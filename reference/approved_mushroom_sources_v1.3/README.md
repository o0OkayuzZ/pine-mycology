# B16–B20 / 個別32×32確認版

今回の新規生成は一覧画像になったため不採用です。このセットは、会話内ですでに作った個別候補5枚を使い、実際の32×32・RGBA PNGへ変換したものです。新規描き直し5枚という扱いではありません。

- `source_candidates/`: 変換元の個別候補を保存。
- `asset_manifest.json`: ID、種名、元ファイル、処理方法の対応表。
